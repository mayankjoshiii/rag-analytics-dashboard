CUSTOMIZATION GUIDE
================================================================================

To adapt for your own data:

1. MODIFY DATA GENERATION
   Edit RandomSeeded class and generate* functions in JavaScript section
   - Change DOC_CATEGORIES for your domains
   - Adjust document counts and distributions
   - Modify query patterns

2. CONNECT REAL DATA
   - Replace synthetic documents with real embeddings
   - Pull actual query logs
   - Integrate with PostgreSQL + pgvector
   - Stream real MCP events

3. ADJUST METRICS
   - Change relevance thresholds
   - Add domain-specific KPIs
   - Implement custom evaluation metrics

4. STYLING
   Update CSS variables in :root section:
   - --primary: #06b6d4
   - --secondary: #a78bfa
   - --bg-dark: #0a0a1a
